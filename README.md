## 🚀 Getting Started

Once the projects are developed, to explore or modify them locally:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Code-Eagl/web-projects.git
   ```



2. **Navigate to the project directory:**

   ```bash
   cd web-projects
   ```



3. **Open the desired project folder:**

   ```bash
   cd project-folder-name
   ```



4. **Open `index.html` in your preferred browser to view the project.**
